paper-resize

Re-paper a PDF between A4, Letter and friends — at true 100% wherever the ink actually fits, and never by more than it has to where it doesn't.

Everything runs inside this tab. Your file is never uploaded — this page is static, it has nowhere to upload it to.

📄
Drop a PDF here or click to choose

When you print this: choose Actual size / 100% in the print dialog. If you leave it on Fit to page the driver will scale the document anyway and everything this tool did is thrown away.

Ink extents are measured by rasterising each page and scanning pixels, so white-on-white rectangles, invisible OCR text layers and clipped content don't count as content. Annotations, links, form fields and bookmark destinations are carried through the same transform rather than dropped.

Built on pdf.js and pdf-lib, both vendored — no CDN, no network calls. Source.
